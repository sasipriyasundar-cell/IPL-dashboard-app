

**Description**

  In this project, I have created an "IPL Dashboard App" which shows the list of ipl teams. By clicking on each team name, the data of the recent matches won and lost by the respective teams can be seen.

  **Concepts Used**
  
  I have used routing, state management and conditional rendering concepts.
  Designed front end using REACT which includes fetch data from an internal server using a class component, displaying that data, using components life cycle methods,  and adding responsiveness to the website.
